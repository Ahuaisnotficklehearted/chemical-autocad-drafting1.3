## 四项绘图规则

### 1. 文字

- 设备附近以短位号为主；完整位号和名称集中对齐，位号在上、名称在下，中间分数线。
- 默认字高3mm；两行中心间距为字高+2mm，分数线放在中间净空，不能穿过文字。
- 用户2026-10-05最新效果图：设备附近短位号中心X等于设备外轮廓包围盒中心X，中心竖轴最低轮廓交点下方10mm为中心Y。含支座，不计外接管口、箭头和文字。集中设备位号表取消；每台设备底部另列“位号—横线—名称”，三者同X，底部位号文字中心在文本框底边上方60mm，默认名称中心再低5mm。固定标注不由文字抛光移动，冲突通过管线／设备布局解决。
- 分数式标注和参数框成组，文字抛光保持组内对齐；外部管线与文字的碰撞仍由现有探测和避障迭代处理。

落地：`chemcad_symbols.add_equipment_tag/add_equipment_labels`、`chemcad_layout.polish_texts`、`chemcad_engine.write_dxf`。字体赋值覆盖生成的标注块定义；默认块输出跳过原生设备块定义。

### 2. 设备布置

- 主流程按已有拓扑从左到右阅读，相关设备保持在同一工段。
- 六页中，塔顶冷凝器、回流罐与回流泵围绕塔顶回路组织，塔底再沸器与泵围绕塔底回路组织。把这类回路强排在同一基线上，会拉长回流线并增加交叉。
- 开始绘图先识别设备模块和工艺职能，查新版图库块，再组织回路。工艺名称和实际连接提供依据；不能仅凭换热器类别推断其为冷凝器或再沸器。
- 自动量尺现在把默认标注包络纳入ELK节点占位；物理设备包络与文字占位分开保存，锚点仍是图库已登记的图面连接点，管线穿设备的代价也使用原设备包络。
- 用户设备 `at` 和管线 `via` 保留优先级；设备标注的旧 `tag_at`／`beside` 被最新固定中心规则取代。规划预留同一标注包络。语义上的上下分区是绘图组织规则，现有ELK仍按拓扑计算，不声称已经实现专门的塔系模板排版。
- 图库登记的连接点用于PFD图面接续；当前新版块部分连接点取自图形包络，不能当作机械设备管口位置的证据。

落地：`chemcad_layout.measure_equipment/EqBox/cost_of`。调用时保留原拓扑、工段与具名设备块；缺块按用户规则确认，不能从这些样本的散实体自行造设备。

### 3. 物流标注

横向流股按 `assets/stream-annotation-reference.png`，菱形顶部竖线接上方框；竖向按用户补充 `assets/stream-annotation-vertical-reference.png`，从菱形右顶点向上引线接右侧框。两列三行F/T/P参数、实际单位和两位小数沿用；流量取W优先、其次F/V，不猜单位、不换算类型，其余字段仅进入独立物料表。

尺寸沿用浙工大0117实体测量：菱形边长10mm、框25×15mm、栏宽10/15mm、行高5mm、字高3mm、字宽因子0.7、外露竖引线5.5092936mm。竖向从右顶点量取引线；这是复用既有尺寸，补充截图没有提供新的毫米测量依据。参数框、引线及菱形与其他流股线/其他标注最小净距3mm；菱形保守采用外包矩形，仅自身承载直线豁免。成组选位或重排管线，容量不足时报错。ACI2/7配色及图层体系保留。

落地：`chemcad_symbols.add_stream_data/stream_annotation_rows`、`draw_pfd._route_pipes`；管旁和cross/same/plant接续共用同一入口。

### 4. 管线组织

- 主物料线保持正交；循环线优先外围上下通道，向设备真实管口接入，保持流向与连接关系。
- 编号和箭头放在足够长的直线段，避开转角；箭头还避开编号菱形和已放箭头。
- 直线段不足以容纳编号时明确停止；所需箭头无法全部放下时进入出图前错误报告，应加长或重排管线，不静默丢弃箭头。
- 保留现有ELK折点、A*避障、显式 `via` 和交叉断线处理。新规则改变标注位置，不改变物流连接或自行增加分支。

落地：`chemcad_engine.PipeRec.straight_point_at/ChemDrawing.add_arrows/preflight` 与 `draw_pfd._route_pipes`。本次同时修正 `pipe(arrows=...)` 只登记箭头而没有实际绘制的问题，使其调用同一绘制入口。
