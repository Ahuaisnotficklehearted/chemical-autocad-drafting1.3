# 化工图纸绘制约定（AutoCAD / DXF）

## 一、先判断图纸类型，再定画法深度

| 类型 | 表现 | 深度依据 |
|---|---|---|
| **P&ID（管道及仪表流程图）** | 设备+管道+阀门+**仪表与控制回路** | HG 20519.2 §3.3，**A1 横幅**，不按比例但示相对高低 |
| **PFD（工艺流程示意图）** | 设备+主物料线+主要参数 | 低于 P&ID，不要求全仪表。**本技能只出这一种图**（`layout-and-collision.md` §8.5）：默认即为 PFD，交付 **DWG**，经 **AutoCAD COM** 出图 |
| **设备布置图** | 平面图 + 剖视图（须有一张整体剖视） | HG 20519.3，标高基准 **EL±0.000** |
| **管道布置图** | 平面图为主，辅以局部剖视/轴测图 | HG 20519.4，比例 **1:50** 常用 |

> ⚠️ **机械图（换热器/容器）已于 2026-09-23 移出本技能范围**（GB/T 28712 系列、GB/T 151
> 不再属于本技能），故本表不再列它。

> **图面内容范围（本技能约定）**：**PFD 不含管径与设备规格。**
> 管径属**管道布置图 / 管道特性表（管线表）**，设备规格属**设备数据表 / 设备一览表**。
> 因此从已有图或模型文件里提取信息时，**不去识别这两项，也不把它们当成「缺失」**——
> 它们属于「本任务不需要」，而不是「本该有却没取到」。
> 用户**已给出**就照标；**没给就不补、不编造**。
>
> （注：管道**等级**分界线（`L1B`/`M1B`）与异径管标注属 P&ID 的正常内容，见 §四末，
> 不在此豁免范围内。）

## 二、线宽与文字（HG 20519.1 第6章）

| 项 | 规定 |
|---|---|
| 粗线 | **0.6 ~ 0.9 mm** |
| 中粗线 | **0.3 ~ 0.5 mm** |
| 细线 | **0.15 ~ 0.25 mm** |
| 分区界线 | 粗双点划线 0.6~0.9；小区分界 中粗双点划线 0.3~0.5 |
| 图纸数字/字母 | **2 ~ 3 mm** |
| 表格文字（格高<6mm） | **3 mm** |
| 手写 | **已取消**（2009 版起） |

**布线铁律**：物料线、仪表连接线、控制信号线一律**水平/竖直正交**，转弯只 90°，**禁止斜线**。

## 三、图层体系（两套方案）

**方案 A — 数字序号命名（用户既有样本）**
`1 主物料` `2 次物料` `3 设备外轮廓` `4 设备内轮廓` `5 图框标题栏` `6 箭头` `7 流股接续` `8 文本` `9 物料代号框` `10 阀门` `11 冷公用工程` `12 热公用工程` `13 电动气动信号线` `14 仪表` `15 仪表连接线` `16/22 设备位号` `18 氮气` `19 保温层` `20 防静电` `21 消防水/泡沫`

**方案 B — 语义命名（站点图例，推荐用于脚本校核）**
`EQUIP` `INST` `仪表` `仪表线` `PIPE_PRI` `PIPE_INLINE` `AF_PIPE` `MISC` `BORDER` `_Grid` `_Cutline` `_Border`

> **选择建议**：需要按图层做自动校核（线宽、线型、闭合性）时用**方案 B**；交付给采用序号制的设计院时用**方案 A**。**同一项目内不要混用**。

## 四、标题栏字段

**中文版**：设计 / 职责 / 制图 / 校对 / 审核 / 描图 / 审定；姓名 / 签名 / 日期；专业名称 / **比例**；名称 / 设计项目 / 设计阶段；图号 / 版次 / 第 X 张 共 Y 张

**英文版**：`REV` `DESCRIPTION` `AUTH'D` `PRE'D` `CHKD` `APPR` `DATE` `PROJ. MAN`；说明 / 设计 / 项目经理 / 校核 / 审核 / 审定 / 日期

> HG 20519.2 要求：同一管道号仅管径不同→只注管径；**管道等级不同→须表示等级分界线并注出等级**（如 `L1B`/`M1B`）；异径管以**大端×小端**表示（`150×100`）。

## 五、控制方案附图：闭环要求（P&ID 的硬标准）

必须能沿 **被控对象 → 测量点 → 控制器 → 输出 → 最终控制元件** 闭合追踪。
**只有设备外形 + 一个仪表圆 + 装饰线 = 工艺示意，不是控制方案附图。**

| 回路 | 画法要点 |
|---|---|
| 单回路反馈 | 对象→测量/变送→控制器→输出→执行机构 |
| 串级 | 副测量点**必须实际落在**副变量管线/设备上，不能只画两个控制框 |
| 前馈-反馈 | 扰动测量点与被控变量反馈点**分别取信号** |
| 分程 | 一个控制器输出经分程功能块到两只阀，执行端分别落在**实际管线** |
| 多冲量 | 每个冲量有独立测量点与信号线（锅炉三冲量：液位+蒸汽流量+给水流量） |
| 旁路 | **真实管线** + 旁路阀 + 回到明确节点 + 流向箭头 |

**P&ID 上必须标注的特殊要求**：设备间相对高差最小尺寸、**液封管最小高度**、异径管定位、**安全阀入口管道压降受限时注明管段长度及弯头数量**、火炬/放空管最低高度、流量孔板前后直管段、管线坡向坡度、阀门**锁开/锁关**。

**调节阀必注**（国标要求）：传动形式（**气动/电动/液动**）、**气开或气闭**、有无手动机构、有无排放阀。

## 六、DXF 文字转义（写/解析脚本必知）

| 转义 | 含义 | 例 |
|---|---|---|
| `%%c` | ∅ 直径 | `2-%%c20` → 2-∅20 |
| `%%d` | ° 度 | `60%%d±5%%d` → 60°±5° |
| `%%p` | ± | `1%%p1` |
| `\A1;` | MTEXT 对齐码前缀 | `\A1;1804` |

**非 ASCII 在 DXF 中常以 `\U+XXXX` 转义**，解析时须还原为字符。

## 七、出图前验收清单

- [ ] 图纸类型与深度匹配（P&ID 不等于 PFD）
- [ ] 线宽符合 0.6~0.9 / 0.3~0.5 / 0.15~0.25
- [ ] 所有线**水平/竖直正交**，无斜线
- [ ] 设备位号**两处标注**（图上下方正对设备 + 设备近旁仅位号）
- [ ] 每根管道**编号 + 流向箭头**；跨图接续用空心箭头并注明图号
- [ ] 管道等级分界线已标注
- [ ] 控制回路**闭环可追踪**（测量→控制器→执行端）
- [ ] 调节阀已注**气开/气闭**、传动形式
- [ ] 特殊要求（液封高度、孔板直管段、坡向）已标注
- [ ] 图层体系**单一且一致**
- [ ] 标题栏字段完整（含比例、版次、张数）
- [ ] **不因「缺管径 / 缺设备规格」而阻塞交付**——PFD/P&ID 不含这两项，**不是缺陷**（见 §一 注）
