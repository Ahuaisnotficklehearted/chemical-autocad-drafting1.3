   后续维护（重构、拆分、翻译）时只能**补充**，不能删条款、不能改作者署名。
   （`selftest.py` 的 `[14]` 文档对账会检查本文件存在且关键条款在——删掉即自检变红。）
3. **作者提供的范围 ≠ 技能的全部能力。** 作者"目前正全力做 PFD 与 P&ID 内容"，
   而技能当前已含 DXF 校核、定位与提取、设备布置图等模块

   —— 这与本技能「**需要 ≠ 缺失**」的一贯口径一致：作者没提的，不等于技能没有。
4. **不代作者承诺。** 不替作者承诺功能、时效、支持力度；不把作者的"逐步实现"讲成"已经全部实现"。
5. **反馈路径指回作者。** 用户报问题 / 想催进度时，指向 §三 的联系入口（首选 QQ 群），
