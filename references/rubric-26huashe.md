# 制图标准：《"工程图纸质量"专项评审》评分实施细则（2026）

> 本文件把**评审标准**落成技能的第一等依据。在此之前，引擎的全部校验器都是
> **自证**的——线宽对照自家 `LAYER_REGISTRY` 的档位声明，图幅对照自家 `SHEET_SIZES`。
> 这类校验有个结构性盲区：**它永远发现不了"登记表本身写错了"**。
> 评分标准是这套技能拿到的第一个**外部基准**。
>
> 可执行化：`scripts/chemcad_score.py`（每条判据都带标准原文 `basis`）。
> ```bash
> python scripts/chemcad_score.py spec.json --drawing-type pfd --json score.json
> ```

## 一、标准原文的结构（共 20 分）

| 章 | 内容 | 分值 | 本技能 |
|---|---|---|---|
| 一 | 格式规范性：PFD 1 分 + P&ID 1 分 | 2 | ✅ 判据已实现 |
| 一 | 车间设备布置图 1 分 + 分厂平面布置图 1 分 | 2 | ❌ **超出范围**：本技能不含示意设备布置图，照实标 `out_of_scope` |
| 二 | PFD —— 内容正确性与完整性 | 5 | ✅ 覆盖 |
| 三 | P&ID —— 内容正确性与完整性 | 5 | ⚠️ 判据已实现，但**本技能只出 PFD**（不含 P&ID 图型） |
| 四 | 设备布置图 —— 内容正确性与完整性 | 3 | ❌ **超出范围** |
| 五 | 总平面布置图 —— 内容正确性与完整性 | 3 | ❌ **超出范围** |

**超出范围的分数照实标 `out_of_scope`，不静默省略**——否则报告会给人"满分"的错觉。

⚠️ **只出 PFD 后的口径**（2026-09-23 更新，与 `chemcad_score.py` 实测一致）：
`score_drawing(cd, dtype="pfd")` 只评 `scope ∈ {pfd, both}` 的条目，
**`pid`（16 条 / 5.6 分）与 `layout`（18 条 / 4.0 分）都不参与**——
既不计入满分、也不假报得分。所以一次 PFD 自评的满分是 **6.0 分**（pfd 21 条）。
`rubric()` 全表 59 条合计 20 分里，P&ID 那 5.6 分属于"判据在、但当前图型用不上"，
**不是"本技能能出 P&ID 图"**——这两件事别混。

## 二、标准点名的三张表 / 三种装帧件

标准把"图面之外的东西"单独给了分，这些是本技能**曾经完全没有**的：

| 件 | 标准条款 | 分值 | 说明 |
|---|---|---|---|
| **完整物流表** | 二.2.1~2.6 | **1.5** | 独立成表：物流号 / 质量流量与质量分率 / 密度与体积流量 / 操作参数 / 相态与相态分率 |
| **设备位号一览表** | 二.3.2 | 0.5 | 图中**顶部或底部**标位号 + 对应设备名称 |
| **图例** | 一.1.3 / 一.2.4 | 0.4 | 设备图例（符号）正确 |

> ⚠️ 这里有个载体问题值得记牢：引擎一直**逐条**在管线旁注流股数据块
> （`add_stream_data`），读起来方便，但标准要的是**一张表**——"物流号完整"
> 这种判据在校验器看来一条都对不上。**载体不对，内容再全也拿不到分。**
> 同理，位号标在符号旁边（二.3.1）与"顶部/底部成表"（二.3.2）是**两条独立的分**。

## 三、两张宽度/高度表（标准直接引用 HG/T 20519-2009）

### 3.1 图线宽度（表 6.1.3）

| 类别 | 图线宽度（mm） | 备注 |
|---|---|---|
| 主物料管道 | 0.6～0.9（一般取 0.8） | |
| 其他物料管道 | 0.3～0.5（一般取 0.4） | |
| 其他 | 0.15～0.25（一般取 0.25） | **设备、机器轮廓线 0.25mm** |

> ⚠️ **最容易被想当然的一条**：设备轮廓看着像"主线"，很容易登记成粗线。
> 标准恰恰相反——P&ID/PFD 里**主物料管道才是粗线，设备、机器轮廓线要 0.25mm**。
> 本技能曾把 `EQUIP` 登记为 `coarse`（0.70 mm），自家校验器一路绿灯，
> 而真实评审的扣分理由里明写着「**设备轮廓线宽不符合规范要求扣 0.1**」。
> 现改为独立档 `outline`（`LW_OUTLINE = 25`）。

### 3.2 文字高度（表 6.2.2）

| 书写内容 | 推荐字高（mm） | 常量 |
|---|---|---|
| 图名 | 7 | `TEXT_H_TITLE` |
| 图表中的图名及视图符号 | 5～7 | |
| 工程名称 | 5 | |
| 图纸中的文字说明及轴线号 | 5 | `TEXT_H_NOTE` |
| 图纸中的数字及字母 | 2～3 | `TEXT_H_MAIN` / `TEXT_H_SMALL` |
| 表格中的文字 | 5 | `TEXT_H_TABLE` |
| 表格中的文字（格高小于 6mm 时） | 3 | `TEXT_H_TABLE_SMALL` |

> 标题栏内的文字高度标准**明确"暂不作要求"**，故标题栏单列 `TEXT_H_TB`，
> 不参与上面这张表的判定。

## 四、设备位号与名称的标注方式（HG 20559.7-1993 §2）

标准原文：

> **2.0.1** 设备名称以**汉字**标注，其名称应与化工工艺专业发表的工艺设备表中的名称一致。
>
> **2.0.2** 在工艺物料流程图、工艺控制图和管道仪表流程图中，**以分母表示设备名称，
> 分数线以粗实线绘制，以分子表示设备位号**。

所以符号旁的正确形态是**分数式**：

```
       T-101            ← 分子 = 设备位号
    ──────────────      ← 分数线 = 粗实线（独立图层 TAGBAR，粗档）
    脱轻塔（精馏塔）      ← 分母 = 设备名称
```

位号的构词规则（§3.0.1 / §3.0.3）：

* **前部**＝1~2 位大写字母表示**设备类别**；**后部**＝3~4 位数字，
  其中前 1~2 位是**工序（主项）代号**，后 2 位是**工序内同类设备的顺序号**。
* 即 `T-101` ≡ 工序 1 + 顺序 01；`E-0101` ≡ 工序 01 + 顺序 01。两种写法都合规。

> ⚠️ **字母表有个坑，不要照 1993 版的类别表硬改**：
> HG 20559.7-1993 §3.0.2 给的类别字母是 C(换热器) / D(反应器) / E(塔) / J(泵) / F(储罐)，
> 与业界的英文首字母习惯（E 换热器 / R 反应器 / T 塔 / P 泵 / V 罐）**不一致**。
> 实际怎么做，看**真实通过评审的图纸**：华东理工大学数支队伍的评审扣分记录里
> 反复出现的是 `V0101`、`E0101`、`T0101`、`P0102`、`F0301` —— **英文首字母习惯**。
> 结论：沿用 T/E/R/P/V，**但把"上下关系"和"分数线"按标准做对**。
> 真实扣分理由里出现过「**设备位号上下不对应，-0.1**」，扣的正是这个。

**直接验证（不靠推断）**：把三份真实竞赛 P&ID 的 DWG 转成 DXF 后逐条读文字实体，
位号前缀频次如下——

| 图 | 前缀频次（前列） | 位号样例 |
|---|---|---|
| 浙江大学 P&ID | E 16 / V 7 / C 3 / D 2 | `E0302` `V0303` `E0307` `R0301` |
| 浙江工业大学 P&ID | E 29 / V 11 / T 6 / R 2 | `E0214` `T0203` `V0205` `R0201` |

即 **E=换热器 / V=容器 / T=塔 / R=反应器**，英文首字母习惯，成立。
另注意数字是 **4 位**（`0302` = 工序 02 + 顺序 02），不是 3 位——
HG 20559.7 §3.0.3 允许"3~4 位"，但**实际通行的是 4 位**；
本技能示例规格用的是 3 位（`T-101`），两种都合规，**新项目建议按 4 位起编**。

## 五、管道组合号（HG/T 20519 §12.2；标准三.2 共 1.4 分）

标准把它定义成**一个字符串**，逐段给分：

```
物料代号 － 主项编号 － 管道序号 － 管道规格 － 管道等级 [－ 绝热代号]
   0.3       0.2        0.2        0.3       0.2        0.2
```

> ⚠️ **拆行就等于丢分**。旧实现把等级画在管线**下方另起一行**，看着清楚，
> 但组合号里那一段"不存在"→ 3.2.5 归零。绝热代号同属末段，且标准注明
> 「**有此项而没有标注的不得分**」。
> 规格里写 `pipes[].insulation`（H 保温 / P 保冷 / T 伴热）即自动续在末段。

## 六、单元控制逻辑（标准三.1，共 3.6 分）

四个被控对象各 0.8 分：**分离塔 / 换热器 / 泵流量 / 反应器**。判据按
**被控设备的类型**（`loops[].controlled_object` → `equipment[].type`）走，
而不是去匹配回路的命名——`loop_type` 写的是回路**结构**（single/cascade…），
拿它当"管的是哪台设备"用，四条会全部判成"没有"。

> 实例教训：本技能的自动排版示例原先只有 3 条回路（反应器进料 F、塔顶 T、塔釜 L），
> **换热器与泵根本没控制方案** —— 按标准直接丢 1.6 分。
> 内容正确性不是"图画对了"就算，**工艺方案本身得齐**。

## 七、标准还管、但容易漏的细节

* **图框**（一.1.1/1.1.2）：幅面按 GB/T 14689-2008，**装订边 25mm** 留在左侧，
  其余三边按幅面取 10（A0/A1）/ 5（A2/A3/A4）。
* **标题栏**（一.1.2.3）：须有**竞赛队名称**，且**项目设计的设计、审核由不同人员承担**。
  真实扣分记录里有「审核两人签字，-0.05」「制图和校对在同一天不合理」。
* **图幅**（一.2.3）：**一般采用 A1**，内容比较少时采用 A2。
* **P&ID↔PFD 一致性**（三.1.5/3.1.6，各 0.2 分）：主要工艺设备数量位号一致、
  工艺流股的连接关系及流向一致。
  ⚠️ **本技能改为只出 PFD 之后，这 0.4 分结构性拿不到**——没有第二张图可比对。
  已照实标 `out_of_scope`（不计入满分，也不假报得分），
  而不是让它跑出"未同时出 PFD/P&ID → 0 分"去拉低真实得分率。
  原先"同一份规格 `--drawing-type both` 出两张图、构造上必然一致"的说法已作废。

## 八、设备布置图（四，3 分）—— ⚠️ 不在本技能范围内

> **2026-09-24 更新**：本技能已**放弃示意设备布置图**——`chemcad_plotplan.py` 与
> `chemcad_equip_geom.py` 已删除，评分里"车间布置图（一）""设备布置图（四）"整体改为
> `out_of_scope`（标准里确有这 4 分，但不产出、不计入分母、不假报）。下面这段是**历史实现记录**，
> 留作口径参考，不再对应任何可执行代码。

四的条款曾可执行化（`chemcad_score.py --drawing-type layout`），出图走
`chemcad_plotplan.py`。**判据分两层，报告里必须分开说**：

| 层 | 数据来源 | 审的是什么 |
|---|---|---|
| **设计数据判据** | 规格 `plotplan` 段实算 | 位差、格位唯一性、标高区间、楼层柱网 |
| **图面判据** | `cd.meta["plotplan_cells"]` + 文字实体 | 净距、位号、标高、尺寸**真的注出来了没有** |

只做前者 → "设计对但图上没注"；只做后者 → "注了但设计不合理"。两条腿缺一不可。

### 比例：示意式的代价，如实承认

标准四「比例」0.1 分，常用 1:100。**本技能不出示意式布置图**，
因此 `chk_scale_honest` 专门检查"名言是否一致"：

* 比例栏写 `1:100` → **只有当图真按该比例画时才成立**；
* 示意式就写「不按比例（示意图）」，**这 0.1 分主动放弃**。

> 为什么宁可不拿这 0.1 分：图不是 1:100 却标 1:100，下游按图量安全间距会得出错误结论，
> 而且**是在他那边出错**，这边一切正常。**标错的比例比不标更危险。**

示意图仍然保留的是：**定位尺寸与标高标真实数值**（引自规格，与图形比例无关），
所以标准四.3 的尺寸与标高类分数照拿。

### 判据自己咬出的三处口径错误（都已修）

1. **"上下层平面布置统一"不能写成"每层分区集合相等"** —— 二层只盖车间一部分是
   **正常的工程做法**（上部平台不必铺满全场）。改成"**同一分区在各层的列位置
   （柱网）必须一致**"，这才是"统一"的真实含义。
2. **"标注基准"是本技能第一次明确写出来的口径**：立面标高 `base` 指**基础顶面**，
   平面定位以**基础中心**为基准。标准只说"基准不正确扣 0.3"却不写该用哪个，
   **那就在技能里明写判据**，而不是含糊过去。
3. **建构筑物尺寸**：平面图原先连轴线与柱距都没有，等于该项完全缺失。已加轴线
   （CENTERLINE）+ 柱距/轴线总长注记（真实数值，规格 `plotplan_grid`）。

## 九、超出范围的（8 分）

分厂平面布置图（1 分）与总平面布置图（五，3 分），以及总平面相关的格式分，
本技能**不产出**。诚实的做法是：

1. 在报告里列出并标 `out_of_scope`，**不计入分母**、也不假装拿到；
2. 需要这两类图时，走 `cad-design-and-drafting` 等机械/总图方向的技能，
   它们管比例（1:500）、风玫瑰、技术指标、安全间距（GB 55037 / GB 50160）、
   消防措施这些条款。
